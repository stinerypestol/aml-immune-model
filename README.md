# Simulating Cancer Cell Growth and the Immune System in Acute Myeloid Leukemia

This repository contains the code and simulations for the master's thesis of Stine Fiskå Rypestøl, completed in the Department of Physics at the Norwegian University of Science and Technology (NTNU).

The aim of this thesis is to investigate the combined effects of the immune system and cancer treatments in Acute Myeloid Leukemia (AML), with a focus on immune suppression due to treatment toxicity, and resistance development.

## Repository Contents

### `aml-immune-model.ipynb`
A Jupyter Notebook containing the full implementation of the model, simulation results, and visualisations.

### `Dockerfile`
Used to reproduce the environment for running the simulations.

### `requirements.txt`
Lists all necessary Python packages for running the notebook.
